# UK Road Accident Severity

Visualization and analysis of factors associated with road accident severity in Great Britain (STATS19, 2021–2025), including a difference-in-differences evaluation of Wales' default 20 mph policy.

Course project (Dự án công nghệ), UET – VNU Hanoi. Work in progress; full README in week 4.

## Structure

```
data/raw/         raw DfT / MIDAS files (not committed)
data/processed/   cleaned Parquet (not committed); agg/ = small aggregates for the web
data/reference/   Data Guide, code tables, DATA_LOG.md
docs/             project rules, tasks, decisions
notebooks/        EDA and analysis notebooks
src/              ETL and analysis code
app/              Streamlit app
reports/          weekly reports, final report, slides
tests/            pytest tests
```
